KnotzDoom

A complete Doom-style first person shooter written in Python with pygame: a grid raycaster with sliding doors, six hand-built levels, four weapons and five monster types.

Run it Source on GitHub

Features

  • Six levels from the Hangar Bay to the Cyber Throne, with story text, par times and a boss fight.
  • Four weapons: pistol, shotgun, chaingun and a rocket launcher whose splash hurts you too.
  • Five monsters that see you, hear gunfire, open doors and path around each other.
  • Doors, keycards, secrets, exploding barrels, soulspheres, armor and an automap.
  • Full game flow: title screen, four skill levels, options, intermission tallies, four save slots, classic cheats.
  • Pure Python engine with auto detail scaling; about 6 ms per frame in the timedemo.

Run it

KnotzDoom is a desktop game. It needs Python 3.10+.

git clone https://github.com/KnotEnvy/KnotzDoom.git
cd KnotzDoom
pip install -r requirements.txt
python main.py
